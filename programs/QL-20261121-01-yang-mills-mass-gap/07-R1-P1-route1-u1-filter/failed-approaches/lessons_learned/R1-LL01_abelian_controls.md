# R1-LL01: on abelian controls
1. 3D U(1) confines at all couplings (S-129), so it is not a negative control for a gap mechanism. Use 4D U(1).
2. U(1) small-field block averaging is linear, so it is not a test of θ-equivariance of non-abelian block maps (R1-FE01).
3. "Effective coupling exceeds a small γ" does not separate SU(N) from U(1). Villain U(1) is non-confining up to g² = 0.168 (Guth), and numerically the Wilson U(1) Coulomb phase starts at g₀² ≈ 1 (R1-E01). A crossover criterion must encode a non-abelian, non-perturbative property (R1-D01 §3).
