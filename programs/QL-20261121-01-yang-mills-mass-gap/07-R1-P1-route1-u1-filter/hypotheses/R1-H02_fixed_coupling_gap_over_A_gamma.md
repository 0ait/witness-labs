# R1-H02: uniform clustering over the fixed-coupling class 𝒜_γ (H-Gap); the real obstruction of R1
- **Label:** Hypothesis (Open problem). Plausibly at least as hard as a fixed-β lattice mass gap for Wilson SU(N) (Chatterjee S-122 Problem 5.1-type), if 𝒜_γ contains the Wilson action at β = 2N/γ (Heuristic).
- **Statement.** ∃ m_γ > 0 and a coarse-local family 𝒮′ such that every ν ∈ 𝒜_γ satisfies 0 ≤ ⟨θF̄′;τ′_nF′⟩_ν ≤ C(F′,ν)e^{−m_γ n}.
- **Role.** H-Bal + H-Gap ⇒ X ⇒ (U) on 𝒦_β (R1-D03 Prop. 2, D08.3). This removes β from the problem.
- **Constraints proved or derived here.**
  - (a) It is false for the U(1) analogue (R1-D01 Lemma A, conditional on (M)), so any proof must use non-abelian structure.
  - (b) The expected m_γ ~ exp(−1/(2b₀γ)) (Heuristic) is non-perturbative in γ.
  - (c) Strong-coupling expansions do not apply: a factor ≈480 mismatch in β_eff at γ=0.1 (R1-D04).
- **Depends on:** R1-D01, R1-D03, R1-D04, R1-E02.
