# R1-H01: volume-uniform Balaban control up to the γ-exit scale (H-Bal)
- **Label:** Hypothesis (Open problem). It is not asserted in any text we opened.
- **Statement.** For SU(N), β ≥ β₀ and a θ-equivariant block map (R1-D02 Prop. 5), the effective densities ρ_k for k ≤ k_*(β)−1 satisfy Balaban's small/large-field bounds (S-119 Thm 1 form) with constants independent of the number of blocks. Their polymer representation has an infinite-volume limit ν_β lying in a β-independent class 𝒜_γ (R1-D03 Prop. 2).
- **Evidence.**
  - Balaban's bounds are local (polymer-localised; BIJ [P] "multi-scale cluster expansion").
  - BIJ [P] state the goal of bounds "uniform in the lattice spacing and in the volume" for the Higgs model.
  - S-007/S-119 are stated on a periodic lattice (finite volume).
  - Jaffe–Witten (S-001 [P]) say Balaban's results "need to be extended".
- **What would have to be added.**
  - Volume-uniform constants in the large-field R-operation (vacuum-energy subtraction per block).
  - Uniform localisation decay rate.
  - Compatibility with the θ-equivariant averaging (R1-H03).
- **Filter status:** group-blind (it should hold for U(1) too).
- **Depends on:** R1-D01 S3/S5, R1-D02.
