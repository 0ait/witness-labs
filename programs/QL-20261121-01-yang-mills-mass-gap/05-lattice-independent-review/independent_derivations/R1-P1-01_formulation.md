# LATTICE blind formulation — QL-20261121-01 / R1-P1
Written 2026-11-21 (CT) after reading only packet §A–B (lines 1–24 of `queue/outbound/QL-20261121-01-R1-P1-v1.md`), my own prior files (baseline, check-in §(i), INV-001 review v1), and the governance folder. Sections C–I, the report and the supporting files had **not** been read when this was written. Shared machine: independence means separate reasoning and code, not isolation.

## 1. Objects
- Fine theory: Wilson measure on (aZ)^4 ∩ torus Λ_L, S = β Σ_p (1 − (1/N) Re tr U_p) for SU(N); for U(1), S = β Σ_p (1 − cos θ_p). Bare g² ≡ 2N/β (SU(N)), 1/β (U(1)). (Conventions must be stated in every number; see §5.)
- Block map B: fine links on blocks of side ℓ (in lattice units) → one coarse link per coarse bond, gauge covariant: B(U^g) = B(U)^{g|coarse sites}. Iterating k times gives the coarse lattice of spacing a_k = ℓ^k a. The pushforward μ'_{β,k} = B^k_* μ_β.
- X (hypothesis, my reading): there are a physical length a_*, a rate m_* > 0 and, for each pair of bounded coarse-local gauge-invariant observables F, G, a constant C_{F,G}, such that for every β ≥ β_0, with k(β) chosen so that a_{k(β)}(β) ∈ [a_*, ℓ a_*), and for every L (or uniformly as L → ∞),
  |⟨F · τ_n θ G⟩_{μ'} − ⟨F⟩⟨G⟩| ≤ C_{F,G} e^{−m_* n}, n = number of coarse time steps.
  Uniformity is in β **and** L, with C_{F,G} allowed to depend on F, G only through their coarse support/norm.
- ME1 on coarse observables: the same decay, written in physical units: rate Δ in physical time t = n a_*. So m_* = Δ a_* is unit bookkeeping. I expect **X ⇔ ME1|_coarse to be a near-tautology** once both are written with the same family, the same quantifiers (∀β ≥ β_0, ∀L) and the same constants. The only non-trivial content of an "equivalence" would be (i) the family (coarse-measurable vs. coarse-local after k(β) steps, whose fine support grows like ℓ^{k(β)} lattice units but is fixed in physical units), (ii) the order of quantifiers on C_{F,G}, (iii) whether τ_n is a symmetry of μ' (needs B to commute with time translations by a_k), (iv) whether a_k only lands in a window [a_*, ℓa_*) rather than exactly a_* (rate then known only up to factor ℓ).
- What X is *for*: D08.1/D08.3 turn X (plus A = T^{ℓ^k} ≥ 0, i.e. RP / transfer-matrix positivity) into a spectral bound on the cyclic subspace generated by coarse observables. That needs B to intertwine θ (so the coarse measure is RP, or at least ⟨F θF⟩ ≥ 0 survives) — otherwise only clustering, not a spectral statement, follows.

## 2. What a 4D U(1) go/no-go filter must test
Fact base (to be verified against opened sources, not assumed): 4D compact U(1) lattice gauge theory has a massless (Coulomb) phase at large β (Guth 1980 for the existence of the deconfined phase / perimeter law; Fröhlich–Spencer 1982 for a massless photon, i.e. power-law decay of field-strength correlations, Villain action at least) and a confined, massive phase at small β (Osterwalder–Seiler 1978 strong coupling, any compact group). So U(1)_4 is the canonical negative control: **any step whose hypotheses U(1) satisfies verbatim in its Coulomb phase would prove a false gap.**

Proposed decomposition of R1 (my labels; QUASAR's may differ):
- S1 block map: gauge covariance, translation covariance, θ-intertwining, RP of μ'.
- S2 per-step RG bounds (Balaban small-field/large-field): valid while g_k² ≤ γ, on which volumes.
- S3 running: g_k² grows (asymptotic freedom, b₀ > 0). For pure U(1), b₀ = 0 (no charged matter): the coupling does not run at weak coupling.
- S4 reaching the crossover: ∃ k_* with g_{k_*}² > γ, with k_* ≈ (const)/(b₀ g²) finite for every β.
- S5 the effective action at k_* lies in a class 𝒞 (polymer/cluster-expandable, possibly non-local with decaying tails).
- S6 clustering of every measure in 𝒞, uniformly in L.
- S7 pull back (D08.3).

Expected filter answer before reading QUASAR:
- S4 fails for U(1) at large β (no running). But this is **not** the whole story: for U(1) with bare 1/β already in (γ, g_c²) (Coulomb phase, β > β_c ≈ 1.0 for Wilson U(1)), the "crossover" g² > γ holds at k = 0, and the theory is still massless. So **S6 (or S5→S6) must also fail for U(1)** unless the class 𝒞 carries information beyond "g² > γ". Hence: "g_k² > γ ⇒ clustering" is false as a group-blind statement for any γ below the U(1) critical coupling; it can only be true if γ is above every abelian-type transition or 𝒞 encodes non-abelian structure (e.g. no centre/Coulomb massless modes). Asymptotic freedom (S3/S4) is therefore **not** the only place non-abelian structure must enter; the absence of a phase transition between the exit coupling and the cluster-expansion regime must also be non-abelian (or proved by a group-specific argument).
- This conclusion only requires: U(1) Coulomb phase extends to couplings g² > γ for the γ in question, and coarse-local block observables of U(1) are massless there (block averages of a massless photon should have power-law decay, but that is a separate statement from Fröhlich–Spencer's point observables — it must be checked, not assumed).

## 3. Expected failure points (for my attack)
1. The S6 failure argument needs a statement about **coarse/block** observables of U(1), not just fine field strength; a block-spin pushforward could in principle decouple the photon only if the block map annihilated it, which a gauge-covariant average should not do. Needs an argument (lower bound on a connected correlation).
2. Balaban's results: finite torus, small-field/large-field split, bounds per step only while coupling small; uniformity in L and the final step(s) are the gaps. Must check the primary papers (CMP 1984–89) — likely title/abstract-level only for us.
3. θ-intertwining: a corner-anchored averaging (parallel transport from a block corner) is not reflection symmetric unless the reflection plane and the anchoring convention are compatible; a failure may be a convention artifact (plane through block centres vs. block boundaries, link orientation reversal U ↦ U^{-1} under θ for time-like links, which corner is used after reflection). Real obstruction only if no symmetric gauge-covariant averaging exists — which I expect does exist (e.g. centre-anchored / symmetrised).
4. Cluster-expansion threshold conversions: factor-of-N, factor-of-2, Re tr vs tr, 1/N in front of tr, d − 1 factors. Expect any rigorous threshold to be O(10^{-2}–10^{-1}) in Wilson β and Balaban's exit to be β ≫ 1: a gap of one to three orders of magnitude is plausible; the exact number depends on γ, which is a free parameter of the RG (smaller γ ⇒ larger β_eff).
5. "H-Gap at least as hard as fixed-β gap": the expected reduction is H-Gap ⇒ (gap on the coarse cyclic subspace of the fine lattice theory at each large β). It is a reduction only modulo cyclicity (coarse observables need not be cyclic for the fine transfer matrix) and with H-Gap stated for the effective (pushforward) measure, not a modified one. The reverse direction (fixed-β gap ⇒ H-Gap) should fail because H-Gap needs β-uniformity.
6. Monte Carlo U(1) vs SU(2): expect only qualitative evidence (Coulomb vs confining behaviour of Wilson loops/correlators) at small volume; check thermalization, autocorrelation (integrated τ), jackknife/binning error bars, and the U(1) metastability near β_c ≈ 1.01 (first-order, long tunnelling times).

## 4. Candidate strategies I would use for H-Gap (pre-registered, to compare later)
- Group-specific transition exclusion: centre-symmetry / centre-vortex free energy bound at the crossover (non-abelian input = trivial π₁ of SU(N) vs. U(1) monopoles).
- Computer-assisted (interval) RG step(s) bridging γ to the cluster-expansion threshold.
- Functional-inequality route for the coarse measure (Poincaré/LSI with coarse-local constants), with the U(1) Coulomb phase as built-in negative control.

## 5. Conventions I will use
Wilson SU(N): S = β_W Σ_p (1 − (1/N) Re tr U_p); g² = 2N/β_W (SU(2): β_W = 4/g²). U(1): S = β Σ_p (1 − cos θ_p), g² = 1/β. Any other source's β is converted to β_W explicitly.
