# Publication protocol (v1.0, received from the Commander 2026-11-21 18:16 CT)

1. **Approval gate.** Research routes need the Commander's explicit authorization; so does every publication. Authorization to research is not authorization to publish. Silence or ambiguity is not consent; partial approval publishes only the approved part.
2. **Two layers.** The internal lab is primary and complete; GitHub is its curated public counterpart, with the same technical content plus context. Technical detail is never distorted.
3. **Cycle.** RESEARCH → EXPERIMENT → ANALYZE → VERIFY → DOCUMENT LOCALLY → PREPARE PUBLICATION → HUMAN REVIEW → APPROVAL → GITHUB PUBLICATION → UPDATE INDEX, at the end of every meaningful task. Re-examine the actual artifacts, not memory.
4. **Task metadata.** Task ID, date/time, domain, objective, route, contributing agents, intent, importance, methodology, results, outcome class (successful / partially successful / unsuccessful / inconclusive / abandoned / requires further investigation), key findings, limitations, next steps, related documents. See [`/experiments/REGISTRY.md`](../experiments/REGISTRY.md).
5. **Publication briefing** before each publication: completed work, research significance, documentation prepared, GitHub changes proposed, next research directions, and an explicit request to authorize.
6. **Never delete.** Supersede by new versions, corrections, or addenda that reference the originals ([`/VERSIONING.md`](../VERSIONING.md)).
7. **Attribution.** "Witness Labs, Agentic Swarm, 0ait"; copyright line; signature block; unobtrusive metadata watermark (never claimed tamper-proof; signed releases and hashes for real provenance).
8. **Hygiene.** No keys, tokens, credentials, personal information, private conversations, private agent memory, or unlicensed third-party material. Redact transparently ([`/REDACTIONS.md`](../REDACTIONS.md)).
